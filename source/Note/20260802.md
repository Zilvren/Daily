## redis

### redis rehash

为了维持哈希表负载因子平衡，需要对哈希表大小进行扩展和收缩，通过执行$rehash$来完成。





$RDB$ 文件就是 $Redis$ 内存数据在某个时刻的二进制磁盘快照，用来备份和恢复数据。

$copy-on-write:$创建子进程时先不复制全部内存；父子进程暂时共享同一份物理内存，只有某一方要修改内存时，操作系统才复制相关部分。

$Redis$执行 `BGSAVE` 或 `BGREWRITEAOF` 时，如果同时对哈希表进行扩容、缩容或$rehash$，会修改大量内存地址，从而触发大量$COW$复制。

渐进式$rehash:$扩展或收缩哈希表需要将 `ht[0]` 里面的所有键值对 $rehash$ 到 `ht[1]` 里面， 但是， 这个 $rehash$ 动作并不是一次性、集中式地完成的， 而是分多次、渐进式地完成的。
